Skeleton and multi-tenancy

Win: Postgres runs, migrations apply, and every row belongs to exactly one venue.

Step 1 — Scaffold and deps

uv run django-admin startproject config .
uv add "django>=6.1,<7" django-environ "psycopg[binary]"

Project package is config, not bookr (that name belongs to the repo). Then create only this lesson's apps:

uv run python manage.py startapp venues

Venue and Membership live together in venues — one tenancy app, since a membership is meaningless without its venue. Later lessons add their own app the same way — nothing before its time. Delete the generated tests.py/views.py stubs: tests live in a top-level tests/ directory from day one (it grows into unit/api/e2e in lesson 9), views arrive per chapter.

Step 2 — Compose stack

Start Postgres — one command, no compose files yet (those arrive in lesson 10):

docker run -d --name bookr-db -e POSTGRES_PASSWORD=bookr -p 5432:5432 postgres:18

Then CREATE EXTENSION IF NOT EXISTS btree_gist in the new database (lesson 3's constraints need it). Check: pg_isready -h localhost answers.

Step 3 — Settings split

Split config/settings.py into config/settings/{base,dev,prod}.py driven by django-environ (DATABASE_URL now; REDIS_URL and EMAIL_URL arrive with their services in lesson 5). Keep the generated defaults: USE_TZ = True, TIME_ZONE = "UTC". Point DATABASES at Postgres via psycopg (ENGINE django.db.backends.postgresql). Check: uv run python manage.py check is clean.

Step 4 — Tenancy core

In venues/models.py, the tenant plus a queryset mixin every scoped model will use:

class Venue(models.Model):
    slug = models.SlugField(unique=True)
    name = models.CharField(max_length=200)
    time_zone = models.CharField(max_length=64, default="UTC")
    late_cancel_hours = models.PositiveSmallIntegerField(default=8)
    appointment_late_cancel_hours = models.PositiveSmallIntegerField(default=24)
    forfeit_late_cancel = models.BooleanField(default=True)
    waitlist_hold_minutes = models.PositiveSmallIntegerField(default=60)
    booking_buffer_minutes = models.PositiveSmallIntegerField(default=10)

class VenueQuerySet(models.QuerySet):
    def for_venue(self, venue):
        return self.filter(venue=venue)

Add middleware resolving the venue (staff profile, else X-Venue-Slug header) and stashing it on the request. In venues/models.py: Membership(user, venue, role) with roles owner/manager/teacher/frontdesk/member and UniqueConstraint(venue, user). Permission class IsVenueMember: deny cross-venue with 404, not 403 (no id leaks — see glossary).

Step 5 — Seed + prove it

Write venues/management/commands/seed_demo.py: 1 venue + users/memberships (1 teacher, 5 members). No rooms or classes — scheduling doesn't exist yet; lesson 3 extends the seed, lesson 6 adds passes. Then the isolation test (plain pytest, in tests/): venue A's member GETs venue B's object → assert 404. Run:

uv run python manage.py makemigrations
uv run python manage.py migrate
uv run python manage.py seed_demo
uv run pytest tests -q

Add a GET /healthz view returning 200 (lesson 9's pipeline will ping it).
