Skeleton and multi-tenancy

Win: docker compose up gives web + db + redis + worker, and every row belongs to exactly one gym.

Step 1 — Scaffold and deps

uv run django-admin startproject config .
uv add "django>=6.1,<7" django-environ "psycopg[binary]"

Project package is config, not bookr (that name belongs to the repo). Then create one app per domain at the repo root:

uv run python manage.py startapp gyms
uv run python manage.py startapp members
uv run python manage.py startapp scheduling
uv run python manage.py startapp bookings
uv run python manage.py startapp passes
uv run python manage.py startapp aggregators
uv run python manage.py startapp access

Delete the generated tests.py/views.py stubs you won't use yet — tests live in tests/ (lesson 10), views arrive per chapter.

Step 2 — Compose stack

Write docker-compose.yml with web (build ., runserver), db (Postgres with btree_gist — needed for lesson 3's constraints; enable via a CREATE EXTENSION init script), redis, worker (celery), beat, mailpit. Check: docker compose up db redis stays healthy.

Step 3 — Settings split

Split config/settings.py into config/settings/{base,dev,prod}.py driven by django-environ (DATABASE_URL, REDIS_URL, EMAIL_URL). Keep the generated defaults: USE_TZ = True, TIME_ZONE = "UTC". Point DATABASES at Postgres via psycopg (ENGINE django.db.backends.postgresql). Check: uv run python manage.py check is clean.

Step 4 — Tenancy core

In gyms/models.py, the tenant plus a queryset mixin every scoped model will use:

class Gym(models.Model):
    slug = models.SlugField(unique=True)
    name = models.CharField(max_length=200)
    time_zone = models.CharField(max_length=64, default="UTC")
    late_cancel_h = models.PositiveSmallIntegerField(default=8)
    appt_late_cancel_h = models.PositiveSmallIntegerField(default=24)
    forfeit_late_cancel = models.BooleanField(default=True)
    hold_ttl_min = models.PositiveSmallIntegerField(default=60)
    buffer_min = models.PositiveSmallIntegerField(default=10)

class GymQuerySet(models.QuerySet):
    def for_gym(self, gym):
        return self.filter(gym=gym)

Add middleware resolving the gym (staff profile, else X-Gym-Slug header) and stashing it on the request. In members/models.py: Membership(user, gym, role) with roles owner/manager/teacher/frontdesk/member and UniqueConstraint(gym, user). Permission class IsGymMember: deny cross-gym with 404, not 403 (no id leaks — see glossary).

Step 5 — Seed + prove it

Write gyms/management/commands/seed_demo.py: 1 gym, 1 room, 1 teacher, 5 members. Then the isolation test (API layer, DRF APITestCase): gym A's member GETs gym B's object → assert 404. Run:

uv run python manage.py makemigrations
uv run python manage.py migrate
uv run python manage.py seed_demo
uv run pytest members -q

Add a GET /healthz view returning 200 (lesson 10's pipeline will ping it).
