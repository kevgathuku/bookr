Map and prereqs

One deploy, many venues. A member books a seat, pays in pass credits, can waitlist or cancel late, can arrive via an aggregator, and can open the door with a booking. Eleven lessons build exactly that.

Step 1 — Confirm your tools

Run these; fix anything that errors before continuing:

python3 --version   # want 3.14+
docker --version    # services run in containers (orchestrated in lesson 10)
uv --version        # project uses uv, virtual project (no src/ build)

Check: uv run python --version inside the repo prints 3.14.x. If bare python hits a mise-shim error, run direnv allow once (the .envrc already activates .venv) or prefix everything with uv run.

Step 2 — Read the contract

Read SPEC.md §§1–3 end to end — roles, booking rules, ledger rules. The tutorial is the walking path; the spec is the law. Skim the glossary and use its words from now on (say forfeit, not penalty; hold TTL, not timeout).
