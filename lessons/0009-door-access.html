Door access

Win: a knock on POST /api/access/check gets grant/deny in under 200ms — and an outage never opens the door.

Steps

  1. Grant iff active pass, or confirmed booking in [-15min, +duration], or staff role. Per-controller tokens, lean hot path, every attempt logged to AccessEvent with its reason.
  2. Redis validity cache (60s TTL) with DB fallback. Fail-closed: DB down → deny + log; drill it, don't just believe it. Anti-passback replays the prior decision within ~60s.
  3. Recent events visible to frontdesk; door_grants_total metric emitted.

Deliverables — check them off

Primary source

Django cache docs — the Redis TTL pattern the hot path depends on.
