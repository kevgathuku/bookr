# Teaching notes

- Wants Flask Mega-Tutorial style: small working app at the end of every step, chapters build in order.
- Asked for lessons with deliverables that can be checked off on completion — checkboxes persist per browser via `assets/app.js`.
- Workspace generated from `TUTORIAL.md` (contract: `SPEC.md`; tickets: `.scratch/bookr-platform/spec.md`).
- Naming bar: explicit units on first sight (`class_late_cancel_hours`, not `late_cancel_h`); no unexplained abbreviations in fields or sketch variables.
- Audience: web-experienced developers learning Django/Python nuances — each lesson teaches Django's opinions (transactions, autodiscovery, TestCase semantics), never web basics.
- `MISSION.md` is a draft inferred from context — confirm or revise when the user reacts.
