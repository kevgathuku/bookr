Bookr reference

Testing cheatsheet

Assert visible behavior — seat granted, credit moved, door denied — never internals.

The seams (highest first)

  1. Booking service: book_seat / cancel_booking / promote_waitlist — one seam for classes, waitlist, cancels, credits.
  2. Availability: pure generate_slots — no database needed.
  3. Aggregator booking endpoint — channel seam.
  4. Door check endpoint — read-only seam.

Non-negotiables

  • Last-seat race (20 threads → exactly 1 confirmed) and last-credit race — mandatory, run in CI.
  • Cross-venue access must 404, not 403.
  • Late-cancel boundary tested at window ± 1 minute.
  • Ledger invariant: sum of deltas equals cached balance, asserted on seed data.

CI order

ruff + black --check → mypy (services/models) → pytest -x → playwright @smoke
nightly + pre-release: full @e2e
