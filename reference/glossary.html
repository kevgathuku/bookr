Bookr reference

Glossary

One meaning per term. Lessons use these words and no synonyms.

TermMeaning
Venue / tenancyOne tenant on the shared platform; every tenant-scoped row carries its venue.
Membership / roleA user's role (owner, manager, teacher, frontdesk, member) scoped to one venue.
ScheduledClassOne concrete session: class type + room + teacher + time window + capacity.
BookingA member's seat claim (or aggregator's), with status: confirmed, waitlisted, cancelled, cancelled_late, no_show, completed.
Waitlist (derived)FIFO order by booking creation time; position is computed, never stored.
Hold TTLMinutes a promoted waitlister has to claim the seat (default 60).
Late cancelCancel inside the venue's window (default 8h classes, 24h 1-1); forfeits the credit.
StrikeA late cancel or no-show; 3 in 30 days flags the member for throttling.
PassProduct / MemberPassA sellable bundle (credits or unlimited) and one member's instance of it.
CreditLedgerAppend-only credit movements; balance is always the sum of deltas.
FIFO spendOldest valid applicable pass is consumed first; unlimited passes before credit bundles.
Idempotency keyClient-supplied unique key making a retried booking return the original, not a duplicate.
AllotmentMax seats one aggregator may hold per class; enforced as min(allotment, free seats).
AggregatorThird-party platform reselling the venue's classes via a scoped token API.
AccessPoint / AccessEventA door controller, and the logged record of every grant/deny decision.
Fail-closedOn outage the door denies; an outage never becomes an open door.
Anti-passbackRe-entry within ~60s replays the prior decision without a new event.
ExclusionConstraintPostgres constraint forbidding overlapping time ranges per room/teacher/resource.
select_for_updateRow lock inside a transaction serializing racers on one class or pass.
